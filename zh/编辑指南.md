# 编辑指南

自新博物馆 Wiki 是**成文资料库**，不再承担提案、草稿、互评和确认工作。所有共创中的内容统一进入[论坛“设定提案与互评”](https://forum.novark.wiki/c/setting-proposals)；达到可发布状态后，再由编录员整理到 Wiki。

## 去哪里进行工作

- **提出新设定、发布草稿、征求互评、讨论修订：** 前往[论坛设定区](https://forum.novark.wiki/c/setting-proposals)。
- **招募、团务和论坛团正文：** 分别使用论坛的“招募与团务”和“进行中的战役”分区。
- **错字、断链、排版等小型勘误：** 使用页面上的“查看讨论”入口回复；编录员可直接修正，不必另开设定提案。
- **改变事实、规则或世界结构的修订：** 必须先在论坛开主题讨论，不能直接把 Wiki 当作草稿区。

论坛主题被编录员标记为“已锚定”后，Wiki 才新建或更新对应成文页面。跑团结果若要成为主设定，也必须先在论坛另开设定提案。

## 编录权限与页面格式

只有 Wiki.js 的“编录员”组可以创建和修改页面。除维护旧页面的特殊布局外，统一使用 Markdown 编辑器；不要在单页加入 `<script>`、`<style>` 或大量内联样式。

页面路径采用 `/世界名/分类/条目名`，以长期归属为准。标题使用设定中的正式名称；目标尚未成文时保留普通文字，不要提前建立空页面。

## 发布检查表

发布成文页面前，编录员应确认：

- 论坛主题已经标记为“已锚定”，正文与最终结论一致。
- 页面有准确标题、一句话摘要和清楚的标题层级。
- 标签包含 `状态-成文`、`世界-<名称>`、`层级-核心/重要/普通/衍生`。
- 规则页面按需增加 `规则-DND3.5E`、`规则-DND5.5E`、`规则-DND5R` 或 `规则-通用`。
- 内部链接、表格、图片和术语引用能够正常打开。
- 重大页面含有“讨论与决议”段落，并链接对应论坛主题。
- 外部素材和跑团整理内容已经确认授权、许可与署名。

## 讨论与决议

重大页面在文末使用以下简短格式：

```markdown
## 讨论与决议

- 论坛主题：[主题名称](https://forum.novark.wiki/t/主题编号)
- 编录结论：简述采用、修改或否决了什么。
- 锚定日期：YYYY-MM-DD
```

论坛保存讨论过程和评分；Wiki 只保存最终可读的正文与必要决议摘要。不要把聊天记录、逐条互评或投票面板复制进 Wiki。

## 标签与读者提示

Wiki 不再使用“提案、草稿、待互评、修订中、确认中、占位、模板参考、废案归档”等工作流标记。原生标签是编录和 AI 检索的主要元数据。

仍可按需要使用 `需要改进`、`剧透警告` 和规则版本标签。页面中现有的“已锚定、核心、重要、普通、衍生、规则版本”等读者提示可以保留，但不得代替原生标签。

## 链接、术语与素材

内部链接文字应直接说明目标，例如 `[弥恩诸世](/弥恩诸世/世界总览)`。需要术语预览时使用保留真实目标的增强链接：`<a href="/页面路径" data-novark-term="术语名">术语名</a>`。关闭 JavaScript 时它仍可访问；理解正文所必需的内容应始终使用普通链接。旧 `{{术语名|/页面路径}}` 只为历史页面保留，不再用于新内容。

图片、地图和图标优先上传本站。单页素材按页面路径归档，公共素材进入统一目录；文件名使用稳定的英文小写、数字和连字符。

Wiki.js 与 Git 会保留修改历史。删除或移动页面前应检查反向链接，并通过重定向保持旧地址可追溯。
