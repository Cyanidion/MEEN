# 编辑指南

自新博物馆维基只保存**已经成文的资料**。新设定必须先在[论坛设定提案区](https://forum.novark.wiki/c/setting-proposals)完成讨论和锚定，再由编录员写入 Wiki。

普通成员不需要在 Wiki 创建草稿、占位或互评页面。错字、链接和格式问题也可在论坛“讨论此页”入口报告。

## 编辑权限与格式

只有编录员可以创建和修改页面。除迁移旧页面或处理特殊布局外，统一使用 Markdown 编辑器。不要在单页加入 `<script>`、`<style>` 或大量内联样式；可复用组件由管理员统一维护。

页面路径采用 `/世界名/分类/条目名`，以长期归属为准。标题使用设定中的正式名称；同名条目通过消歧义页处理。

## 发布检查表

新建或进行事实性修改前，编录员必须确认：

- 论坛主题已经由编录员标记“已锚定”。
- 页面具有准确标题和一句话摘要。
- 标签包含 `状态-成文`、`世界-<名称>`、`层级-核心/重要/普通/衍生`。
- 规则页面按需增加 `规则-DND3.5E`、`规则-DND5.5E`、`规则-DND5R` 或 `规则-通用`。
- 标题层级清楚，表格、链接和术语引用能够正常打开。
- 重大页面包含“讨论与决议”段落，写明论坛主题、锚定结论和日期。
- 外部素材和跑团整理内容已经确认授权与署名。

## 成文状态标记

Wiki 不再使用提案、草稿、待互评、修订中、确认中、占位、模板参考或废案归档标记。

仍可使用：

- `【【已锚定】】`
- `【【核心设定】】`、`【【重要设定】】`、`【【普通设定】】`、`【【衍生设定】】`
- `【【需要改进】】`
- `【【剧透警告】】`
- `【【DND3.5E】】`、`【【DND5.5E】】`、`【【通用规则】】` 和规则双版本组件

状态标记用于读者展示；Wiki.js 原生标签是编录和 AI 检索的主要元数据。

## 链接与术语

内部链接文字应直接说明目标，例如 `[弥恩诸世](/弥恩诸世/世界总览)`。目标尚未成文时保留普通文本，不提前建立空页面。

术语提示写作 `{{术语名|/页面路径}}`，只用于补充说明；理解正文所必需的页面应使用普通链接。

## 资产、版本与决议

图片、地图和图标优先上传本站。单页资产按页面路径归档，公共资产进入统一目录；文件名使用稳定的英文小写、数字和连字符。

Wiki.js 与 Git 会保留修改历史。事实性修改还必须在对应论坛主题记录原因、影响范围和最终决议。删除页面前应检查反向链接，并优先使用重定向保持旧地址可追溯。
