# 荻原自由党

**荻原自由党**（简称荻自党，OLP）是[共和政府](/弥恩诸世/政权组织/弥恩联区共和国)的一个地区性政党。

# 详述

该党目前是{{大议会|/弥恩诸世/术语汇编/大议会}}第三大党，主要在[荻原](/弥恩诸世/人文地理/地理/荻原)大区执政。

荻原自由党于荻原大区在{{肃边战争|/弥恩诸世/历史沿革/历史事件/肃边战争}}中失败，被{{东赐政府|/弥恩诸世/术语汇编/东赐政府}}吞并后成立，最初名为**荻原抵抗组织**。该组织因长期组织地下武装袭击与激进的独立立场，长期被东赐政府列为非法组织。

{{洛托新政|/弥恩诸世/术语汇编/洛托新政}}后，221纪年·玄英时节·2月15日，组织时任领袖[奥利弗·瑞斯迪](/弥恩诸世/人物汇总/奥利弗·瑞斯迪)宣布该党转向正常化，宣布参与大议会与府议会选举。3月20日，荻原自由党在大议会全国选举中获得16个席位，密斯维尔·德布鲁就任党的大议会领袖。

荻原自由党以谋求荻原独立为核心政治目标，着力维护荻原府当地利益与传统，具有浓厚的地区性政党色彩。其支持者绝大多来自荻原籍公民。
