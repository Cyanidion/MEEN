# 大议会

<p><strong>大议会</strong>，是共和政府的最高立法与民意代表机关，与{{共和政府|/弥恩诸世/术语汇编/共和政府}}、{{大审判院|/弥恩诸世/术语汇编/大审判院}}共同构成新宪制下的国家权力体系。大议会负责制定法律、审议税收与财政预算、监督政府、批准重要条约，并通过信任表决决定政府能否继续执政。</p>

<p>第一届大议会共设<strong>199席</strong>，其中<strong>159席为地方选区议席</strong>，<strong>40席为全国不分区议席</strong>。选民在议会选举中分别投下选区票与政党票，两种票分别计算，地方选区的胜负不会直接增减政党取得的不分区席位。</p>

# 议会选区

<p>地方选区实行<strong>单一选区相对多数制</strong>。每个选区选出一名议员，各候选人中得票最多者当选，不要求取得过半数选票。无所属候选人可以参加地方选区选举，但不得提出不分区名单。</p>

<p>议会选区由独立的<strong>选区划分委员会</strong>划定。委员会以登记选民总数除以地方选区席位数，得出全国统一的选举基数；除边疆、灾区及交通长期隔绝地区外，各选区选民人数原则上不得低于基数的百分之九十五，也不得超过百分之一百零五。</p>

<p>选区划分应尽量维持地域连续，并尊重大区、府、郡及城市边界，不得无故拆分长期形成的社区、产业带与交通圈。人口变动较大的地区定期重新划界，但不得仅因某一政党的选举利益临时调整边界。选区草案须公开征求地方政府、政党与居民意见后方可生效。</p>

# 不分区议席

<p>全国不分区议席依政党票分配。各政党须在选举前公布排序名单，取得全国政党票百分之五以上者，方可依得票比例参与40席的分配。议员辞职、死亡或失去资格时，由同一政党名单中的下一顺位递补。</p>

<p>不分区制度用于代表难以集中于单一选区的全国性利益，使工会、专业团体、少数族群及规模较小的政党仍有进入大议会的机会，但不用于抵消各党在地方选区中的胜负。因此，大议会仍以地方选区竞争为政治核心，同时保留有限的比例代表性质。</p>

# 政府组成

<p>选民并不直接选举政府首脑。议会选举结束后，能够取得大议会多数信任的政党领袖或联盟领袖负责组织政府，并由{{综摄|/弥恩诸世/术语汇编/综摄}}依照宪制程序任命。若没有任何政党取得过半席位，各党须通过联合组阁、信任协定或逐案合作形成多数。</p>
