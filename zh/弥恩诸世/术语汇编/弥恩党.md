# 弥恩党

**弥恩党**（简称MP）是共和政府[共和政府](/弥恩诸世/政权组织/弥恩联区共和国)的一个政党，与[民主共和党](/弥恩诸世/术语汇编/民主共和党)并列为共和国两大主要政党。

# 详述

该党目前是大议会第二大党，多在[东赐](/弥恩诸世/人文地理/地理/东锡)大区与各地中小城镇、乡村地区执政。

弥恩党在地域上主要受到**东赐大区**居民的欢迎，而[帝国时期](/弥恩诸世/历史沿革/历史时期/帝国时期)与[东赐政府](/弥恩诸世/术语汇编/东赐政府)时期的传统上层人士，例如旧贵族、大地主、军方高层与不受[三大家](/弥恩诸世/术语汇编/三大家)控制的大资产阶级，则组成了该党的领导团体。该党以“拥抱传统”著称，执政理念更为温和，以保护旧秩序的既得利益者群体为目标，并与守旧势力多有合作。虽然总体而言，该党支持洛托新政及推行改革，但常常阻碍甚至反对[让娜·洛托](/弥恩诸世/人物汇总/让娜·洛托)与民主共和党推行的激进政策，据称大量政治事件背后都有他们的身影。

221纪年·玄英时节·2月10日，与让娜等人理念不合的时任帝国军总督**提格雷·纽斯卡尔**宣布成立弥恩党，并参与大议会选举。3月20日，弥恩党在大议会全国选举中获得45个席位，成为全国第二大党，莱纳·科恩就任党的大议会领袖。
