# 生命领域

生命领域是[薇拉（薇尔诺妮娅）](/弥恩诸世/信仰体系/薇尔诺妮娅)的神职，薇拉也是二十一神中唯一一位拥有生命领域神职的生命。生命领域常表现为对身体伤势的治疗，但这并非生命领域的本质，此领域之力不在于修补，而在于增强生命本身，同时也擅长打击不死生物，是介于神圣领域与医疗领域之间的神职。

## 生命领域特性

| 牧师等级 | 领域特性 |
| :---: | --- |
| 3级 | 生命领域法术、生命门徒、引导神力：维持生命 |
| 6级 | 生命使徒 |
| 7级 | 生命潮涌 |
| 17级 | 引导神力：极效生命 |

## 生命领域法术

当你达到下表所列的牧师等级时，你始终准备着对应法术。这些法术不计入你能够准备的法术数量。

| 牧师等级 | 始终准备的法术 |
| :---: | --- |
| 3级 | 祝福术、疗伤术、次级复原术、援助术 |
| 5级 | 希望信标、生命转换 |
| 7级 | 防死结界、生命灵光 |
| 9级 | 群体疗伤术、反制善恶 |

## 3级：生命门徒

你的治疗法术能够激发目标的生命潜能。
当你使用1环或更高环阶法术恢复一个或多个生物的生命值时，受到该法术治疗的生物在接下来的两轮内，其所有攻击检定与属性检定均获得等于所消耗法术位环阶的加值。

## 3级：引导神力：维持生命

你可以使用引导神力，赋予生命抵抗重伤与伤患的韧性。
作为一个魔法动作，你展示圣徽并消耗一次引导神力，选择距你30尺内数量不超过你牧师等级的生物。目标受到生命能量保护，持续1分钟。

受到保护的生物获得下列效果：

| 效果 | 规则 |
| --- | --- |
| 抵抗重伤 | 重伤与伤患不会对目标产生任何影响。 |
| 抵抗猝死 | 目标不会因为承受伤害而立即死亡。 |
| 维持意识 | 目标的生命值降低至0时不会陷入昏迷。 |
| 死亡豁免 | 生命值为0的目标仍需正常进行死亡豁免检定，并会因死亡豁免失败而死亡。 |

## 6级：生命使徒

你施展的治疗法术也会赋予自身生命领域之力。
当你使用1环或更高环阶法术为另一生物恢复生命值时，你选择获得下列一种效果：

| 效果 | 规则 |
| --- | --- |
| 生命抗性 | 你下一次对抗法术进行的豁免检定，获得等于所消耗法术位环阶的加值。 |
| 生命威权 | 你下一次施展要求其他生物进行豁免检定的法术时，该法术的豁免DC获得等于所消耗法术位环阶的加值。 |

这项加值会在对应的豁免检定发生后消失。

## 17级：引导神力：极效生命

你可以引导神力，将一个物种的生命增强至其所能达到的极致。
作为一个魔法动作，你展示圣徽并消耗一次引导神力，选择距你30尺内一个自愿生物。目标的生命潜能被完全激发，持续1分钟。
在此期间，该目标视为“<a href="/弥恩诸世/增改规则/种族/完美个体" data-novark-term="完美个体">完美个体</a>”，并获得“完美个体”的所有特殊能力。目标死亡或持续时间结束时，此效果结束。
