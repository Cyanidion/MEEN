# 生命领域

生命领域是[薇拉（薇尔诺妮娅）](/弥恩诸世/信仰体系/薇尔诺妮娅)的神职，薇拉也是二十一神中唯一一位拥有生命领域神职的生命，生命领域常表现为对身体伤势的治疗，但这并非生命领域的本质，此领域之力不在于修补而在于增强，同时亦强于打击不死生物，是介于神圣领域与医疗领域之中的神职。

## 生命领域特性

| 牧师等级 | 领域特性 |
| :---: | --- |
| 3级 | 生命领域法术、生命门徒、引导神力：维持生命 |
| 6级 | 生命使徒 |
| 7级 | 神圣打击 |
| 17级 | 引导神力：极效生命 |

## 生命领域法术

当你达到下表所列的牧师等级时，你始终准备着对应法术。这些法术不计入你能够准备的法术数量。

| 牧师等级 | 始终准备的法术 |
| :---: | --- |
| 3级 | 祝福术、疗伤术、次级复原术、援助术 |
| 5级 | 希望信标、生命转换 |
| 7级 | 防死结界、生命灵光 |
| 9级 | 群体疗伤术、反制善恶 |

## 3级：生命门徒

你的治疗法术能够激发目标的生命潜能。

每回合一次，当你使用1环或更高环阶法术使一个或多个生物恢复生命值时，你可以选择其中一个目标。该目标获得激励，持续至你第二个回合结束。

在持续时间内，目标可以在进行一次攻击检定或属性检定后，为该检定添加等于所消耗法术位环阶的加值。目标必须在知晓检定是否成功前决定是否使用该加值。使用后，激励立即结束。

同一生物无法同时获得多个由生命门徒提供的激励。

## 3级：引导神力：维持生命

你可以使用引导神力，赋予生命抵抗重创与伤患的韧性。

作为一个魔法动作，你展示圣徽并消耗一次引导神力，选择距你30尺内至多等于你感知调整值的生物，至少可以选择一个。目标受到保护，持续1分钟。

受到保护的生物获得下列增益：

| 增益 | 效果 |
| --- | --- |
| 抵抗重伤 | 重伤与伤患不会对目标产生任何效果。 |
| 抵抗猝死 | 目标不会因为承受伤害而立即死亡。 |
| 维持意识 | 目标的生命值降低至0时不会陷入昏迷，但会陷入失能状态，且速度变为0。 |
| 顽强求生 | 目标仍需正常进行死亡豁免检定。 |

目标恢复至少1点生命值、死亡或持续时间结束时，其因维持意识获得的效果结束。

## 6级：生命使徒

你施展的治疗法术也会赋予自身生命领域之力。

每回合一次，当你使用1环或更高环阶法术为另一生物恢复生命值时，你可以选择获得下列一种生命增幅：

| 生命增幅 | 效果 |
| --- | --- |
| 生命抗性 | 你下一次对抗法术或魔法效应进行的豁免检定，获得等于所消耗法术位环阶的加值。 |
| 生命威权 | 你下一次施展要求目标进行豁免检定的法术时，该法术的豁免DC获得等于所消耗法术位环阶的加值。 |

生命增幅持续至你完成一次长休，或直至对应的豁免检定完成。你同一时间只能保有一种生命增幅，再次获得生命增幅时，原有效果立即结束。

通过此特性获得的加值最高不能超过你的熟练加值。

## 7级：神圣打击

生命领域强化了你的受福打击。

当你触发牧师的受福打击特性时，可以令其额外伤害变为光耀伤害。若受到该伤害的目标是不死生物，受福打击造成的额外伤害骰数量翻倍。

当你达到14级时，你的受福打击额外伤害提高至2d8；对不死生物则提高至4d8。

## 17级：引导神力：极效生命

你可以引导神力，将一个生物的生命增强至其物种所能达到的极致。

作为一个魔法动作，你展示圣徽并消耗一次引导神力，选择距你30尺内一个自愿生物。目标的生命潜能被完全激发，持续1分钟。在此期间，该目标视为“完美个体”，并获得“完美个体”的所有特殊能力。

同一时间只能有一个生物受到此特性影响。目标死亡、你陷入失能状态，或持续时间结束时，效果立即结束。

你使用此特性后，必须完成一次长休，才能再次使用。
